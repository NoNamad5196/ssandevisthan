# 공개 판매처 검증 기록

2026-10-09에 검색으로 발견한 실제 의류 상품 12개의 공개 페이지를 직접 조회했다. **현재 어댑터의 판매처 검증을 모두 통과한 상품은 0개**다. 실제 상품 검색 성공, Similarity Gate 통과, LIVE 추천 성공을 의미하지 않는다. 이미지 비교/OpenAI 호출은 수행하지 않았다.

## 조회 방법과 제한

- 공개 검색 결과의 상품 URL만 사용했다. 검색 요약의 가격·재고는 근거로 채택하지 않았다.
- `SafeFetcher`와 `NodePinnedTransport`로 HTTPS 인증서·공개 DNS/IP·응답 크기·타임아웃을 검증했다. 페이지당 최대 2 MB, 최대 8초, 이번 검증의 실제 상품 페이지 GET은 12회다.
- 처음 4건은 로컬 네트워크 샌드박스의 `EACCES`로 HTTP 전송 전에 거절됐다. 승인된 네트워크 실행으로 같은 4건을 재시도했으며, 이 실패 기록도 로컬 manifest에 남겼다.
- 실제 응답은 모두 HTTP 200이었다. CAPTCHA/접근 차단 우회, 로그인, 장바구니, 구매, 유료 API 호출은 없었다.
- 전체 HTML 및 진단 manifest는 Git에서 제외된 `.cache/merchant-probes/`에만 보관한다. 저장소에는 아래 최소 결과만 남긴다. 재현 명령은 `node --experimental-transform-types .cache/probe-elevenst.mjs <발견된 상품번호>`이며, 스크립트는 중복 및 12회 제한을 검사한다.

## 확인된 한계와 다음 작업

검색 인덱스의 재고 및 JSON-LD `InStock`만으로 현재 구매 가능 여부를 확정할 수 없다. 이번 판매 중지 페이지 일부에도 JSON-LD 재고 정보가 남아 있었지만, 확정 옵션 검증에서 모두 제외됐다. 내부 `selStatCd` 숫자의 의미는 공식 근거 없이 일반화하지 않는다.

`11st-public-size-option-v3-2`는 검증된 현재 상품 제목 뒤 첫 가격 영역의 명시적인 판매 중지 문구를 검사한다. 중첩된 도움말 영역을 포함해 가격 패널 전체를 확인하며, 추천 상품·스크립트·템플릿의 문구는 재고 증거로 사용하지 않는다. 기존의 저장된 12개 응답을 네트워크 없이 다시 파싱한 결과, 판매 중지 8개는 `OUT_OF_STOCK`, 2개 축 상품 2개는 `VARIANT_AMBIGUOUS`, 안내 문서 2개는 `PAGE_NOT_PRODUCT`로 제외됐다. 위 표의 최초 관찰과 HTTP 시각은 그대로 보존했다. 합성 fixture 25개가 통과했으며, 여기에는 판매 중지 문구가 오래된 `InStock`/양수 재고보다 우선하는 회귀 검증이 포함된다.

현재 11st 어댑터는 단일 SIZE 축에 한정된다. 2개 축을 지원하려면 정상 공개 옵션 선택 과정에서 얻는 정확한 색상·사이즈 SKU, 옵션 가격·재고, 해당 색상 이미지의 연결 근거를 추가로 검증해야 한다. 색상 그룹의 합산 재고나 `data-stckno=0`을 구매 가능한 변형의 재고로 사용하면 안 된다.

추가로 기존 `9278059264` 페이지에 표시된 공개 옵션 조회 URL을 확인했으나 응답은 `infoList: []`였다. 빈 응답으로 누락된 변형·가격·재고를 추정하지 않았다. 파이프라인은 정확한 `www.11st.co.kr/products/<숫자>` 경로에서 전용 어댑터를 사용하며, 전용 검증이 실패하면 일반 JSON-LD 추출로 되돌려 통과시키지 않는다.

이 결과를 이유로 국내 판매 조건, 이미지 근거, 옵션 검증, 가격 정책 또는 Similarity Gate를 완화하지 않았다. 다음 단계에는 최신 재고가 있는 적격 판매처의 실제 근거 확보가 필요하다. 테스트 fixture로 이를 대체해 LIVE 성공으로 보고하지 않는다.
