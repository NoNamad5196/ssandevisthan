- 767px 이하: 헤더→브랜드/헤드라인→업로드→콜라주→핫딜 순으로 세로 배치. 사진 업로드 조작이 첫 화면에서 찾기 쉬워야 한다. 데스크톱 전체 PNG를 축소해 작은 글자로 보여주는 방식은 금지한다.
- 모바일 여백 16px, 주요 터치 영역 최소44×44px, 핫딜 검색창과 버튼은 좁으면 두 행. 원본에 없는 햄버거 메뉴·새 내비게이션 항목을 임의로 추가하지 않는다.
- 360×800, 390×844, 768×1024, 1280×800, 1440×900, 1586×992에서 가로 스크롤·중첩·잘린 조작 0건.
- 모바일/상태 화면은 이 규칙으로 첫 기준 캡처를 만들고 버전 관리한다. 원본 PNG에 모바일 화면이 있었다고 주장하지 않는다.
# 5. 기능을 붙이는 위치와 상태
- 업로드 제한 문구는 원본의 **JPG, PNG, WEBP (최대 10MB)**를 유지. API는 10,000,000 bytes를 상한으로 정의한다. 원본 가격·예산 입력란 추가 금지.
- 파일 선택→미리보기/교체/삭제→검색 시작. 첫 업로드 CTA를 유지하고 선택 후 같은 영역에서 검색 버튼을 제공한다. 키보드·드래그앤드롭 모두 동작한다.
- invalid/oversize/unsupported 상태는 업로드 프레임 내부에 한국어 한 문장과 다시 선택 동작을 둔다. 배경색·히어로 구도·로고를 바꾸지 않는다.
- QUEUED/RUNNING은 같은 영역에서 실제 상태 1개와 취소 버튼. 진행률 분모를 모르면 숫자 퍼센트 없음.
- 결과: 실제 상품 이미지→상품명/판매처→일반 가격→비슷한 이유→구매 링크→배송비/확인시각. 새로운 결과 페이지도 같은 토큰·기울기·잘린 모서리·상품 사진 중심 구도를 사용한다.
- TOTAL_PRICE와 ITEM_PRICE_ONLY는 ‘배송비 포함 확인’과 ‘배송비 미확인’으로 구분한다. 코호트 내부 순위만 표시하며 전체 최저가 순위처럼 합치지 않는다.
- 가격 미확인 reference는 추천 결과에 섞지 않고 별도 펼침 정보. 결과가 0개면 억지 상품 카드를 만들지 않는다.
- 핫딜은 원본의 의류/생활용품/국내 새 상품 구조를 유지하는 별도 DEAL_TEXT 검색이다. 사진 유사도 점수를 이 화면에 표시하지 않는다.
# 6. 접근성·표시 정확성
- 원본 로고 이미지 alt는 ‘싼데비슷한’. 순수 장식/콜라주는 의미 중복을 피하도록 decorative 처리. 상품 이미지 alt는 실제 상품명.
- file input에 접근 가능한 label, 키보드 순서, focus 표시, 오류 연결, 상태 aria-live polite. 상품 링크는 판매처가 드러나는 이름을 사용한다.
- 노랑 바탕 cyan 작은 글씨처럼 대비가 낮은 표현은 원본의 큰 아트워크에는 유지하되 기능용 작은 글자는 ink를 사용한다. 새 정보의 가독성을 위해 본문 역할을 원본과 구분하며 히어로 색상을 재설계하지 않는다.
- 가격·회원조건·배송비·갱신시각은 실제 API 값. placeholder 가격을 운영 결과로 노출하지 않는다.
# 7. 디자인 검수 기준
1. 원본 해시 확인 → 고정 브라우저/OS/DPR1/폰트 버전 → 1586×992 캡처 → 50% opacity 오버레이와 차이 이미지 → 항목별 판정 순서로 검수한다.
2. 원본과 직접 비교할 영역: 헤더, 로고/제목, 업로드 프레임, CTA, 콜라주, 핫딜 띠. 구현에서 기능을 붙인 상태는 별도 기준 캡처로 검수한다.
3. **즉시 실패**: 로고 형태 변경, 제목 줄바꿈/위계 변경, 노랑·검정 면적의 큰 변화, 콜라주 누락/평범한 카드로 대체, 일반 폰트로 대형 로고 재작성, 임의 영문 HUD, 상품 사진 색보정, 업로드 동작이 보이지 않음.
4. 초기 허용오차: 주요 패널 기준점 ±4px, 고정 벡터/아이콘 간격 ±2px. 초기 픽셀 차이 예산 1%는 같은 렌더 환경의 자체 baseline 회귀에만 사용한다. 원본 PNG와 DOM의 차이를 숫자 하나로 통과시키지 않는다.
5. 폰트: 지정 WOFF2 실제 로드, 역할별 weight·자간·행간, 한글 줄바꿈·가격 숫자 정렬을 확인. 로고 래스터와 입력 텍스트는 따로 검수.
6. 모션: hover130ms/상태180ms, 이동 상한, focus/press, reduced motion을 녹화 및 computed style로 확인. 정지 스크린샷만으로 모션 PASS 금지.
7. 모든 viewport와 idle/파일선택/검색중/완료/부분실패/빈결과/오류/예산제한 상태에 캡처를 남긴다. 실제 판매처 사진은 테스트 fixture로 고정한다.
8. 검수 기록: `designVersion, assetHash, fontHash, viewport, DPR, browser, state, screenshot, diff, reviewer, result, deviations`.
9. 현재 기록: PNG 직접 열람과 문서 명세 작성 완료. 프론트엔드 실행물·픽셀 회귀·모션 검수는 아직 수행하지 않았다.
